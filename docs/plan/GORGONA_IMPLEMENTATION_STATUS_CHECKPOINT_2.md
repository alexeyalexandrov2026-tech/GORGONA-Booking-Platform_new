## Результат текущего пакета

Технически проверены исправления основы записи и черновик бизнес-профиля. Вся универсальная платформа еще не реализована.

- Полный мастер-план исправлен с сохранением всех 39 направлений, нумерации и согласованных отраслевых процессов. Уточнены владение данными, единая занятость, защита выплат, порядок материальных операций, ответственность продавцов, допуск провайдеров, приемка и архитектура Azure.
- Добавлен типизированный каталог 39 стабильных ID с сопоставлением 20 секторов NAICS. Отрасли отделены от B2B/B2C, маркетплейса, франшизы и холдинга. Статус полного отраслевого цикла у всех профилей пока `planned`.
- Реализованы GET бизнеса/каталога и PUT черновика профиля в `/v1/businesses/{id}`. `business_id == tenant_id == legacy salon_id`: новая компания и второй экземпляр существующих данных не создаются.
- Миграция 0008 добавляет три FORCE-RLS таблицы с составными ссылками внутри компании. Заголовки версий и дочерние выборы неизменяемы после фиксации. Миграция успешно применена только к одноразовым тестовым базам PostgreSQL 18.6. Рабочие и производственные базы не менялись.
- Сохранение проверяет права, версию и обязательный ключ команды; профиль, выборы, аудит и ответ команды фиксируются одной транзакцией. Проверены параллельные запросы, повтор, другое тело с тем же ключом, устаревшая версия и полный откат при ошибке.
- Добавлена страница `/business/`: поиск, несколько специализаций без дублей, отдельные форматы, собственное необязательное название, черновик, безопасный повтор сохранения, конфликт версий и просмотр без права редактирования. Выбор отрасли не активирует неподготовленный процесс.
- Исправлены ISO-дни недели 1..7, локальные даты филиала, ввод и показ времени, DST, сохранение нескольких рабочих интервалов и окончания в 24:00. Неизвестные часы и длительности не подставляются вымышленными значениями.
- Calendar, Bookings и быстрая запись Overview используют часовой пояс фактического филиала. Settings показывает все интервалы по филиалам. Стоимость подтвержденных записей показана отдельно по валютам и не называется оплаченной выручкой. Поле `today_revenue_cents` сохранено как устаревшая совместимость.
- Ограниченное филиалом членство не превращается в право всей компании. Независимый platform read остается только чтением с аудитом. Полноценные филиальные обработчики еще предстоит реализовать.
- Исправлены настройка реального тестового OIDC, мобильная компоновка и отсутствовавший management test script. Добавлены проверки измененного поведения и unit web в CI. Четыре исходных файла дополнительно приведены к Ruff formatting без изменения логики.
