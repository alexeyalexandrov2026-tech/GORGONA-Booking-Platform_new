## 4. Уже внесенные изменения кода

### Существующая запись и интерфейс

- `web/lib/business-time.ts`: ISO-неделя 1–7; извлечение локальной даты/времени через Intl с заданной IANA-зоной; календарный сдвиг; преобразование локального времени в UTC с отказом для отсутствующего/двойного времени при смене часов. Нужны отдельные регрессионные тесты DST и разных смещений.

- `booking/metrics.py`: стоимость подтвержденных записей группируется по валютам с устранением повторов booking_id при ресурсных соединениях.
- `OverviewStats.today_booked_value` и интерфейс заменяют надпись «Revenue» на стоимость подтвержденных записей. Старое `today_revenue_cents` оставлено deprecated для совместимости и документировано как историческая сумма стоимости, не деньги/выручка. В новых отображениях не использовать его.
